# Day 1 - Network Devices Topology

Basic two-branch network built while following Jeremy's IT Lab CCNA course (Day 1).

## Devices used
- 2x Cisco 2911 routers
- 2x Cisco 2960 switches
- 2x Cisco 5505 firewalls
- 2x PCs, 2x Servers, 1x attacker laptop

## Topology
New York Branch and Tokyo Branch connected through "The Internet" router, each branch protected by a firewall at the edge.
