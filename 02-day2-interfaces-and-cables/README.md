# Lab 2 - Interfaces and Cables

Connecting network devices with the appropriate cable types based on
distance and device type, following Jeremy's IT Lab CCNA course.

## Topology
Two sites connected via a long-distance fiber link (R1-R3, 3km) and a
medium-distance link (R3-R4, 250m). Each site has routers connecting
down to switches in a cascading structure, ending in PCs and a server.

## Key concepts practiced
- Choosing copper vs. fiber based on distance
- Straight-through vs. crossover cable selection
- Auto-MDI-X considerations
